MIGRATION POLICY

No global DEV/PROD toggle

Social Factory keeps its dedicated DEV credential and its allowlisted bridge to the TRUE DEV Radio API. A production Social Factory would require an explicit production service build and approval; this migration does not manufacture one by changing a hostname.
