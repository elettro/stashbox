What it can do

Capability map

The system combines live API Actions, Stashbox production services and native image/file tools behind a conversational interface.

UNDERSTAND

Natural-language production requests

Interprets requests such as “make a campaign with 10 songs, 9:16, 45 seconds” and converts them into exact controlled parameters.

DISCOVER

Live Song CMS selection

Finds eligible songs, resolves titles to exact song keys, filters by artist or genre, selects newest or highest-performing tracks and avoids duplicate songs.

PLAN

Safe campaign proposals

Creates a proposal first, showing selected songs, duration, ratio, asset sources and render count before anything is launched.

RENDER

Video Factory orchestration

Creates render drafts, launches approved jobs, monitors progress, reports failures and moves completed videos into Content Review.

REVIEW

Secure video review

Creates a protected review page, previews private MP4s and avoids exposing signed storage URLs.

EDIT

Metadata and review decisions

Edits title, description, tags, hashtags, collaborators, playlist settings and review notes; supports approve, hold, reopen and hide workflows.

SCHEDULE

Single and batch scheduling

Validates dates first, normalizes Eastern Time, schedules one or many approved items and returns exact schedule names and statuses.

PUBLISH

Controlled YouTube publishing

Publishes only after explicit confirmation, applies visibility and subscriber settings, then stores and reports the final YouTube result.

DEFAULTS

Stashbox YouTube standards

Uses the correct Stashbox channel, Made for Kids off, synthetic-media disclosure on, publication-date recording date and the Stashbox video-library playlist.

VERIFY

Post-publication proof

Checks channel ownership, YouTube video identity, playlist membership, publishing state and final URL rather than merely assuming success.

ANALYTICS

Read-only performance answers

Returns most played, liked or shared songs, including genre-filtered requests such as the five most-played Reggae songs.

CREATE

Six-size SR Profile Image Set

Produces purpose-built 1:1, 9:16, 16:9, 3:4, 4:5 and 21:9 compositions, verifies dimensions and packages six properly named PNGs into a clickable ZIP.

Control model

Power with guardrails

The GPT is intentionally not an unrestricted autonomous publisher. Its permissions and language are designed to prevent accidental execution.

✓

Read-only by default

Status, analytics, candidates, jobs and review items can be inspected without changing anything.

✓

Validation before execution

Render launches, schedules and publishing can be tested first with confirmation fields set to false.

✓

Explicit confirmation

Launch, approve, reject, schedule, cancel and publish operations require immediate confirmation.

✓

Separate credential

The Custom GPT uses a dedicated revocable credential with restricted routes and actor logging.

✓

No invented state

The GPT must use live Actions for IDs, URLs, job state, approval state, schedule state and YouTube state.

✓

Clear lifecycle language

It distinguishes proposed, drafted, rendering, completed, in review, approved, scheduled, publishing and published.

Separate future phases

  • This acceptance is for the private DEV environment. Production hardening and DEV-to-production promotion are a separate phase.
  • Official YouTube collaborator invitations and a Short’s related-video selection still require YouTube Studio.
  • Only YouTube is connected for direct publishing in this completed phase; Facebook, Instagram and TikTok remain future integrations.
  • The GPT does not publish autonomously from vague instructions. High-impact actions remain confirmation-gated.
  • The image workflow requires a usable source image and may need creative iteration when text or composition is unusually complex.
Plain-English explanation: This Custom GPT acts like a private Stashbox content operations producer. It can look at the current catalog and performance data, prepare a campaign, send exact jobs to Video Factory, organize the finished videos for review, apply decisions and metadata, place approved content on a schedule, publish it to the correct YouTube channel and playlist, and then verify that the work actually happened. It also handles the separate six-format artwork-production and ZIP-delivery workflow.
