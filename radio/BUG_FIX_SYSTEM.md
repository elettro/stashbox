# Stashbox Radio Bug & Fix System

For any Stashbox Radio defect, regression, broken behavior, failed render, playback problem, API error, CMS issue, or repair request, start here.

1. Read `radio/docs/bug-fix/AGENT_WORKFLOW.md`.
2. Search `radio/docs/bug-fix/BUG_INDEX.md` and `radio-admin/dev/bugs/bugs.json`.
3. Read the relevant playbook under `radio/docs/bug-fix/repairs/`.
4. Inspect the current implementation and compare with prior repair records before changing code.
5. Create or update the appropriate `SR-BUG-####` record.
6. After the repair, record root cause, files, commit, regression checks, verification state, and future repair procedure.

DEV dashboard: `/radio-admin/dev/bugs/`

GitHub documentation is the permanent source of truth. The dashboard is the searchable operational view.
